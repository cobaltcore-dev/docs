# Governance

CobaltCore is governed and operates under the [NeoNephos Foundation](https://neonephos.org/). Project decisions are made transparently through the structures described below.

## Technical Steering Committee

The Technical Steering Committee (TSC) holds all technical oversight for the project. It sets the direction, coordinates across working groups, and maintains the quality and integrity of the codebase and its processes.

The TSC operates under the [NeoNephos project charter](https://github.com/cobaltcore-dev/.github/blob/main/GOVERNANCE.md) and makes decisions by majority vote. Amendments to the charter require a supermajority.

## Special Interest Groups

Special Interest Groups (SIGs) are focused working groups that own specific areas of the CobaltCore stack. Each SIG maintains its own roadmap, reviews contributions in its domain, and reports back to the TSC.

### SIG Platform

Owns the platform bootstrap layer, including Gardener integration, GardenLinux, IronCore, and the Kubernetes control plane lifecycle.

### SIG Compute

Owns the compute layer, including hypervisor lifecycle, KVM node agent, OpenStack Nova integration, and high-availability scheduling.

### SIG Storage

Owns the storage layer, including Ceph, Rook, Liquid Ceph, Chorus, and the Arbiter monitor.

### SIG Networking

Owns the networking layer, including OVN, OVS, and OpenStack Neutron integration.

### SIG Observability

Owns the observability stack, including Prometheus, Perses, Prysm, and alerting rule coverage across the full stack.

## Code of Conduct

All community spaces and contributions are governed by the [NeoNephos Code of Conduct](https://github.com/neonephos/.github/blob/main/CODE_OF_CONDUCT.md). Violations can be reported per the instructions in the Code of Conduct.
